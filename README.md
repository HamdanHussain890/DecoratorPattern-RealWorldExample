DecoratorPattern-RealWorldExample
This repository contains a Python implementation of the Decorator Design Pattern, created for a Software Design and Algorithm course assignment. It demonstrates a real-world scenario of a text editor applying dynamic formatting styles (Bold, Italic, Underline) using decorators.

🖋️ Text Formatter using Decorator Design Pattern

📌 Overview
This project demonstrates the **Decorator Design Pattern** using a real-world example of a simple **Text Editor**. You can apply multiple text formatting styles (Bold, Italic, Underline) dynamically.

 🎯 Purpose
To understand and implement the Decorator Design Pattern in Python by solving a real-world problem.

⚙️ Tools Used
- Python 3
- OOP (Object-Oriented Programming)
- Design Patterns (Decorator)

🧩 How It Works
We have:
- A base `PlainText` class
- Formatting decorators: `BoldDecorator`, `ItalicDecorator`, `UnderlineDecorator`
- Each decorator wraps the text and adds formatting without modifying the base class.
